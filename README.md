# 医药行业 AI 产品管理系统(产品演示原型)

一套纯前端、零依赖的**高保真产品演示系统**:模拟面向医药行业的 AI 产品管理平台,包含**系统总览看板**与**三个产品模块**(全球文献循证、全球专利、药物警戒)。

> 所有数据均为**虚构演示数据**,用于展示产品设计思路与交互细节。

## 在线预览

```
https://junchuanshu912.github.io/show_i_did/
```

## 部署到 GitHub Pages(一次性设置)

1. 打开本仓库 **Settings → Pages**;
2. **Source** 选择 **"Deploy from a branch"**,分支选 `main`、目录选 **`/ (root)`**,保存;
3. 约 1 分钟后即可通过上方链接访问(此后每次推送新代码自动更新)。

## 本地运行

无需安装任何环境,双击 `index.html` 即可(建议 Chrome / Edge)。

## 系统构成

| 文件 | 说明 |
|---|---|
| `index.html` | **系统首页(总览看板)**:顶部导航、实时 KPI、三大模块数据看板、实时动态流、告警中心;点击模块在系统内嵌打开 |
| `循证智能体.html` | 模块一:全球文献 × AI —— 循证问答(强制引用、证据分级)、系统综述六步工作台、靶点情报监测(订阅管理)、知识库数据看板、评测中心 |
| `IP智能体.html` | 模块二:全球专利 × AI —— 排查项目列表与五步流程、情报地图(领域切换+机会清单)、监控预警(订阅管理)、专利库数据看板 |
| `药物警戒智能体.html` | 模块三:药物警戒 × AI —— PV 工作台、个案智能处理、文献监测、审计合规、信号库数据看板 |

## 交互设计亮点

- 打开模块先弹**欢迎引导卡**(说明用途与体验顺序),顶栏 "?" 可随时重开;
- 每个页面带「怎么体验」提示条与大数字指标;
- 订阅 / 项目支持**增删**(删除需确认、弹层可取消);
- 看板含**实时模拟数据**(入库流水、倒计时、数字实时增长)与环形图、趋势图等图表,均支持悬停反馈;
- 页面跳转全部使用**相对链接**,上传任意静态托管(GitHub Pages 等)即可在线访问。

## 技术栈

HTML + CSS + 原生 JavaScript,无任何外部依赖、无构建步骤。
